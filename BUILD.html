BUILD — Lychee Player

1. 环境要求

↑

项目要求
发行版Arch Linux x86_64；当前不支持其他发行版与 arm64。
构建工具base-devel、nodejs、npm。
运行期依赖GTK、libsecret、NSS、ALSA、D-Bus；可选系统 mpv（原生播放引擎）。

2. 开发运行

↑

npm ci
npm run dev
npm run typecheck
npm test
npm run test:watch
node scripts/probe.mjs
  • npm test 使用 fixture 回放，默认不访问真实上游；录制 fixture 需要显式开关，见 scripts/record-fixtures.mjs。
  • 测试不接入 CI；在本地或离线环境执行。

3. 构建

↑

npm run build

构建产物进入 out/；版本与许可证从 package.json 注入关于页。

4. 打包

↑

npm run package:arch
dist/lychee-player-<version>-x86_64.tar.gz
dist/lychee-player-<version>-x86_64.tar.gz.sha256
dist/lychee-player/
├── lychee-player
├── resources/
├── LICENSE
├── lychee-player.desktop
└── lychee-player.png
  • electron-builder --linux dir 生成目录后由 scripts/package-arch.mjs 整理、补桌面文件与校验和。
  • tarball 顶层固定为 lychee-player/，不包含源码、node_modules、测试或构建缓存。
  • 文件名版本与 package.json 一致，不带 v 前缀。

5. curl 安装

↑

curl -fsSL https://raw.githubusercontent.com/<owner>/lychee-player/main/install.sh | sh
curl -fsSL https://raw.githubusercontent.com/<owner>/lychee-player/main/install.sh | sh -s -- --version 0.1.0
curl -fsSL https://raw.githubusercontent.com/<owner>/lychee-player/main/install.sh | sudo sh -s -- --system
参数行为
--version <ver>选择 GitHub Release 版本；默认最新。
--prefix <dir>用户级安装目录；默认 ${XDG_DATA_HOME:-$HOME/.local/share}/lychee-player。
--system安装到 /opt/lychee-player，需要 root / sudo。
--uninstall删除程序、桌面文件与图标，保留设置与缓存。
--dry-run只打印动作，不写盘。
  • 默认用户级安装：程序目录 ${XDG_DATA_HOME:-$HOME/.local/share}/lychee-player，入口 ~/.local/bin/lychee-player，桌面文件与图标写入用户 XDG 目录。
  • 系统级安装：程序目录 /opt/lychee-player，入口 /usr/bin/lychee-player，桌面文件与图标写入 /usr/share。
  • 安装脚本校验 sha256sum；校验和缺失或不匹配时拒绝安装。也可先下载脚本检查再执行。

6. 手动运行

↑

tar -xzf lychee-player-<version>-x86_64.tar.gz
./lychee-player/lychee-player
  • tarball 可解压到任意目录；未来放入 /opt/lychee-player 不需要改结构。
  • 若 Chromium 沙箱因 chrome-sandbox 权限拒绝，优先启用用户命名空间；系统级安装或未来 AUR 包应设置 4755 root:root。

7. 支持范围

↑

仅 Arch Linux x86_64。其他发行版、arm64、deb / rpm / AppImage 不在当前范围。

8. 后续 AUR

↑

AUR 需要当前产物保证
稳定 source URLGitHub Release 资产名固定 lychee-player-<version>-x86_64.tar.gz。
安装到 /opt/lychee-playertarball 顶层目录固定、内容可重定位。

9. 故障排查

↑

症状处理
沙箱启动失败检查 chrome-sandbox 权限与用户命名空间；系统级安装按 §6 处理。
Wayland 显示异常在启动参数文件写 --ozone-platform=wayland 或 --ozone-platform=x11；见 §10。
密钥环未解锁解锁 libsecret / gnome-keyring 后重启；密钥环不可用时登录被禁用。
缺库安装 §1 运行期依赖。
curl / 校验和失败检查网络、Release 资产名与 sha256sum。

10. 启动参数

↑

默认文件：$XDG_CONFIG_HOME/lychee-player/flags.conf；未设置 XDG_CONFIG_HOME 时为 ~/.config/lychee-player/flags.conf。每行一个参数，空行与 # 开头行忽略；--flags-file=<path> 可指定另一份文件。

# Lychee Player 启动参数（每行一个）
--ozone-platform=wayland
--enable-wayland-ime
--password-store=gnome-libsecret
--autoplay-policy=no-user-gesture-required
  • 优先级：显式命令行 > flags 文件 > 环境变量 > 内置默认。
  • 设置页保存后下次启动生效，不热加载；不提供路径选择。

11. 存储

↑

用途位置 / 说明
歌单缓存userData/cache/playlist；只缓存“我喜欢”，超过字节上限不落盘。
音频缓存userData/cache/audio/<musicid>/；总容量上限与 LRU 清理由 CORE 常量定义。
下载默认 ~/Music/Lychee Player，可在设置页修改；仅本机个人使用。
mpv系统安装的 mpv 可执行文件；IPC socket 在 XDG_RUNTIME_DIR，权限 0600。
