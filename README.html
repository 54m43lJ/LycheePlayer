qqy — 第三方 QQ 音乐 Linux 客户端

1. WHAT & WHY

1.1 IDEAL：我们要解决的问题

腾讯官方的 QQ 音乐 Linux 版基于 Electron，资源占用偏高，MPRIS 媒体控制残缺， 不支持音质选择，无法融入 Linux 桌面生态（托盘、桌面歌词、全局快捷键等）。 我们希望有一个由社区驱动、原生融入 Linux 桌面的 QQ 音乐客户端。

1.2 GOAL：什么算成功

  • 能用自己的 QQ 音乐账号登录，浏览、搜索并播放自己有权收听的内容（含 VIP 曲库按账号权限）。
  • 完整的 MPRIS 媒体控制与系统托盘，行为符合 freedesktop 规范。
  • 可自由选择音质；日常听歌可以完全替代官方 Linux 客户端。
  • 资源占用与启动速度显著优于官方 Electron 客户端。

2. 用户交互

  • 扫码登录 / 粘贴 Cookie 登录，凭证存入系统密钥环。
  • 搜索：单曲 / 歌手 / 专辑 / 歌单 / MV。
  • 播放队列：双击播放、随机 / 循环 / 单曲循环、拖动进度、音量。
  • 歌词：滚动歌词，进阶支持逐字歌词与桌面歌词。
  • 歌单：浏览用户歌单、收藏歌单、每日推荐、雷达歌单。
  • 系统集成：MPRIS、托盘常驻、全局快捷键。

3. 技术栈

层次选型
桌面壳Electron
前端Vue 3 + TypeScript + Vite + Pinia + Vue Router
API 层自研 Node 版 QQ 音乐接口模块（仅参考 jsososo/QQMusicApi 的请求行为，不引入其代码与依赖），独立模块隔离接口细节
播放引擎HTML5 Audio 起步，必要时引入 libmpv（参考 EchoMusic 的 napi 内嵌方案）
歌词LRC 解析渲染起步；逐字歌词参考 jixunmoe-go/qrc 做 QRC 解密
系统集成MPRIS（mpris-service / dbus）、系统托盘、密钥环存凭证（keytar 或 safeStorage）
打包分发electron-builder：deb / rpm / AppImage / pacman，x64 + arm64

4. 功能路线图

MVP

  • 扫码 / Cookie 登录，凭证持久化（系统密钥环）。
  • 搜索（单曲 / 专辑 / 歌手 / 歌单）与搜索结果页。
  • 播放链接获取（128k 起步，按账号权限尝试 320k / FLAC），播放队列与基础控制。
  • LRC 滚动歌词。
  • 用户歌单浏览与播放。

进阶

  • 音质切换、播放缓存。
  • MPRIS 完整实现、托盘、关闭最小化。
  • 每日推荐 / 专属雷达 / 猜你喜欢。
  • 逐字歌词（QRC 解密）、桌面歌词。
  • 收藏 / 歌单管理、MV 播放、下载管理、封面取色主题。

5. 法律与合规边界

  • 本项目为非官方客户端，与腾讯及 QQ 音乐无隶属关系；仅调用官方公开接口。
  • VIP / 数字专辑内容仅通过用户本人的登录凭证获取，不实现任何绕过授权的能力。
  • 上游接口随时可能变更导致功能失效，属预期风险。
