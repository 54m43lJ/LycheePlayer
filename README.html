1. WHAT & WHY

↑

1.1 IDEAL：要解决的问题

腾讯官方的 QQ 音乐 Linux 版基于 Electron，资源占用偏高，MPRIS 媒体控制残缺， 不支持音质选择，无法融入 Linux 桌面生态（托盘、桌面歌词、全局快捷键等）。 本项目希望提供一个由社区驱动、原生融入 Linux 桌面的 QQ 音乐客户端。

1.2 GOAL：什么算成功

  • 用户能用自己的 QQ 音乐账号登录，浏览、搜索并播放自己有权收听的内容（含 VIP 曲库按账号权限）。
  • 完整的 MPRIS 媒体控制与系统托盘，行为符合 freedesktop 规范。
  • 用户可自由选择音质；日常听歌可以完全替代官方 Linux 客户端。
  • 资源占用与启动速度显著优于官方 Electron 客户端。
  • 当前实现为可日常使用的 MVP；后续目标见 TODO.md。

1.3 非目标

  • 不实现任何绕过授权、付费墙或数字专辑限制的能力。
  • 不内置、分发或镜像音乐内容；所有内容均通过用户本人的登录凭证从上游获取。

2. 用户交互

↑

场景行为详细契约
登录 登录页内嵌官方 xlogin 组件扫码（默认），或粘贴浏览器 Cookie（兜底）。凭证加密保存在系统密钥环；密钥环不可用时禁用登录，免费内容的搜索与播放不受影响。 USER §5.2.6
搜索 按单曲、歌手、专辑、歌单四类搜索；结果分页展示；双击歌曲播放，点击歌单卡片进入详情。 USER §5.2.8
播放 双击歌曲或“播放全部”开始播放；支持播放队列、顺序播放、列表循环、单曲循环、随机播放、拖动进度、音量与音质选择；播放条展示实际生效音质。 USER §5.2.3
歌词 LRC 滚动歌词与翻译合并显示；当前行高亮；点击歌词行跳转播放进度；切换路由自动关闭面板。 USER §5.2.5
歌单 浏览当前账号的歌单列表与公开歌单详情；歌单内支持播放全部与单曲播放。 USER §5.2.8
系统集成 通过 MPRIS 暴露媒体控制；托盘菜单提供显示主窗口、播放/暂停、上一首、下一首、退出；关闭主窗口默认隐藏到托盘。 USER §4.1 · §5.4
外观 深色 / 浅色主题；窄屏下自动切换为紧凑布局（断点见 USER §5.2.1）。 USER §5.1
设置 默认音质、主题、关闭到托盘、账号状态、立即续期与退出登录；修改即写盘，无保存按钮。 USER §5.2.7

总体布局示意（深色主题）。原型用于固定区域关系，不是像素级还原；各组件的视觉契约见 USER §5.2。
