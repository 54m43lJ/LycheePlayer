2. CONVENTIONS

↑

约定内容
IPC 通道命名 请求型为 域.动作（如 song.getUrls）；推送型为 域:事件（如 player:state、player:command）。
信封 所有请求型 IPC 返回 IpcResult<T>；主进程捕获一切异常并转为 IpcError，渲染进程不会收到被抛出的异常。
单位与 ID 类型 时长一律毫秒（number）；上游数字 ID 一律转为 string 后跨 IPC 传输。
凭证边界 凭证只存在于主进程 credential.ts；不得跨 IPC、写日志或进入渲染进程。存储实现与密钥环降级见 PROVIDER §2，用户侧边界见 USER §2。
上游隔离 上游原始 JSON 只存在于 api/ 层内部；离开该层的值必须是 §4.1 定义的内部模型。
错误映射 UpstreamError 直接保留其 code；超时 / 中止映射为 UPSTREAM_NETWORK；其他异常映射为 INTERNAL。
日志 日志只写主进程；不输出凭证、Cookie 与完整播放链接。
设置持久化 settings.set 以浅合并更新并立即写盘；加载时对未知值回退默认值。
工程常量 所有工程常量只在 shared/constants.ts 声明；模块只 import；派生常量使用表达式（如 PROBE_MAX_SONGS = PLAYLIST_PAGE_SIZE * PLAYLIST_PAGE_MAX），禁止模块内重复字面量。
缓存作用域 账号相关缓存键必须带 musicid 或 anonymous；退出登录清空歌单缓存与可用性缓存，音频体缓存按账号隔离保留。
启动参数 启动参数文件在模块加载阶段读取并应用；命令行高于文件，文件高于环境变量与内置默认；设置页只读写当前生效文件。
歌单分页 固定 50 首/页；页获取并发受 PLAYLIST_PREFETCH_CONCURRENCY 控制（默认 1）；补全不会取消；队列构建过滤已知不可播歌曲。
可用性探测 探测只更新歌单歌曲元数据，不修改播放队列或当前播放；队列入队时按 playable !== false 过滤。
fixture 回放 测试默认不访问真实上游；请求匹配、脱敏、录制与更新流程见 test/fixtures/ 与 scripts/record-fixtures.mjs。
单实例 应用启动时请求单实例锁；第二个实例只唤醒并聚焦已有主窗口，不创建新进程。
导入省略 签名块省略 import 语句（如 electron 的 BrowserWindow），实现时按需引入。
  • 工程常量统一在 §4.50 声明；推荐值只以注释形式给出，不构成赋值；UI 视觉字面量见 USER §5。

export type ErrorCode =
  | 'UPSTREAM_NETWORK'   // 无法连接上游或请求超时
  | 'AUTH_EXPIRED'       // 凭证过期或无效
