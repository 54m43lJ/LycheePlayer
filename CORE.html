2. CONVENTIONS

↑

约定内容
IPC 通道命名 请求型为 域.动作（如 song.getUrls）；推送型为 域:事件（如 player:state、player:command）。
信封 所有请求型 IPC 返回 IpcResult<T>；主进程捕获一切异常并转为 IpcError，渲染进程不会收到被抛出的异常。
单位与 ID 类型 时长一律毫秒（number）；上游数字 ID 一律转为 string 后跨 IPC 传输。
凭证边界 凭证只存在于主进程 credential.ts；不得跨 IPC、写日志或进入渲染进程。存储实现与密钥环降级见 PROVIDER §2，用户侧边界见 USER §2。
上游隔离 上游原始 JSON 只存在于 api/ 层内部；离开该层的值必须是 §4.1 定义的内部模型。
错误映射 UpstreamError 直接保留其 code；超时 / 中止映射为 UPSTREAM_NETWORK；其他异常映射为 INTERNAL。
日志 日志只写主进程；不输出凭证、Cookie 与完整播放链接。
设置持久化 settings.set 以浅合并更新并立即写盘；加载时对未知值回退默认值。
单实例 应用启动时请求单实例锁；第二个实例只唤醒并聚焦已有主窗口，不创建新进程。
导入省略 签名块省略 import 语句（如 electron 的 BrowserWindow），实现时按需引入。
  • 工程常量在各自源文件的签名小节中声明；推荐值只以注释形式给出，不构成赋值；UI 视觉字面量见 USER §5。

export type ErrorCode =
  | 'UPSTREAM_NETWORK'   // 无法连接上游或请求超时
  | 'AUTH_EXPIRED'       // 凭证过期或无效
  | 'NO_STREAM'          // 各档音质均无播放链接

5.7 会话续期

├── 判断无凭证 → return
└── 判断续期条件 → api/login::refreshSession()
    └── api/login::refreshMusickey(current)
        └── api/client::upstreamRequest('music.login.LoginServer/Login')
            └── credential::saveCredential(refreshed)
  • 续期条件分两种情况：凭证有到期时间时，在 SESSION_REFRESH_AHEAD_MS 窗口内触发；凭证无到期时间时，达到 SESSION_REFRESH_FALLBACK_MS 触发。两种情况都不满足则跳过。
  • 续期失败保留旧凭证并等待下一次重试；启动检查与定时器都会触发该路径。

5.8.1 关闭窗口

5.8.2 应用退出

app.on('before-quit')
├── index::clearInterval(refreshTimer)
├── integration/mpris::publishState(null)
├── integration/tray::destroyTray()
├── api/web-login::disposeEmbedView()
└── settings::saveSettings(settings::getSettings())
  • before-quit 先将 quitting 置为 true，避免关闭窗口被 closeToTray 拦截为隐藏。
  • 退出路径不等待 saveSettings 完成；凭证默认保留，清除仅由 login.logout() 触发。
  • closeToTray 生效时关闭窗口仅隐藏；before-quit 只在托盘退出或应用退出时触发。
