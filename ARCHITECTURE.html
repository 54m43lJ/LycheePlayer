ARCHITECTURE — Lychee Player（第三方 QQ 音乐 Linux 客户端）

1. TERMS

术语定义
songMid歌曲在 QQ 音乐的业务主键（字符串）。上游接口调用与 vkey 请求均以它为标识。
mediaMid音频文件级标识。付费歌曲的 mediaMid 可能与 songMid 不同，vkey 请求的 filename 必须使用它；不进入本地数据模型。
vkey上游签发的音频流访问令牌，附于流 URL 查询参数，有时效，失效需重新获取。
播放链接由上游 vkey 接口返回的相对 URL（purl，含 guid / vkey / uin / fromtag 等查询参数）拼成的音频流 URL，拼装规则见 §4.3。
音质（Quality）128k / 320k / flac 三档枚举。
凭证（Credential）musicid 与 musickey 组成的登录态，可含过期时间戳。加密存储于系统密钥环。
权限某歌曲对当前凭证的可播属性，分免费（free）、VIP（vip）、数字专辑（album）三类，对应 PayInfo。
上游y.qq.com CGI 接口与音频流服务器的统称。
MPRISfreedesktop 媒体播放器 D-Bus 接口规范（org.mpris.MediaPlayer2），本应用对外暴露的媒体控制接口。
信封（IpcResult）所有请求型 IPC 返回值的统一包裹结构，见 §4.2。

2. CONVENTIONS

约定内容
IPC 通道命名请求型为 域.动作（如 song.getUrls）；推送型为 域:事件（如 player:state、login:status）。
信封所有请求型 IPC 返回 IpcResult<T>；主进程捕获一切异常并转为 IpcError，渲染进程永远收不到被抛出的异常。
单位与 ID 类型时长一律毫秒（number）；上游数字 ID 一律转为 string 后跨 IPC 传输。
凭证边界凭证只存在于主进程 credential.ts；不跨 IPC 下发、不写入日志、不进入渲染进程。
上游隔离上游响应在 api/ 层完成规范化，跨入 IPC 的数据只有 §4.3 定义的形态；上游原始结构不透传。
音质降级请求音质无权限时按 flac → 320k → 128k 单向降一档重试；降至 128k 仍无链接则报 NO_STREAM。降档静默，不做提示；实际音质经 UrlResult.quality / PlayerState.quality 呈现。
默认音质defaultQuality 为 auto 时按登录态取档：已登录 flac，未登录 320k；设置页可固定具体档位。
会话续期登录凭证含 refresh_token 时，到期前 10 分钟或每 6 小时经 music.login.LoginServer/Login 换新 musickey 并写回密钥环；失败保留旧凭证等待重试。
UI 调色板深色 / 浅色两套 token 定义见 §5；组件只使用语义变量，不直接写死颜色。

3. DIAGRAMS

3.1 总体架构

  • 音频流由渲染进程直接从流服务器加载，不经过主进程转发。
  • 凭证仅存在于主进程；渲染进程只持有“已登录 / 未登录”状态。
  • MPRIS 命令由 integration 层经 ipc.ts 派发回渲染进程，与播放状态发布共用一条通道约定。

3.2 扫码登录

  • 轮询由主进程定时器驱动；渲染进程只消费 login:status 推送，不参与轮询。
  • 登录页内嵌官方 xlogin 组件（webview），login.openWebLogin() 负责监听换证；createQrKey 的应用内二维码保留为实验路径。
  • 二维码图片由 login.createQrKey() 随创建结果返回（data URL），login:status 只承载状态推进。
  • 登录失败时 login:status 的 stage 为 failed，message 携带可展示的错误摘要（不含凭证）。
  • 登录组件使用独立内存 session（webview partition），只放行 QQ 域名；主进程每秒轮询该 session 的 Cookie，同时看到 p_skey 与 p_uin/pt4_token/uin 才进入换证；5 分钟超时按失败处理。
  • 凭证在主进程内直接入库，任何状态下都不跨 IPC 下发；存储介质见 PENDING #10。

3.3 播放单曲

  • 为保持时序图单一分支，音质降档重试（§2）在图中省略，其发生位置在 api/song.ts 内部。
  • player:state 推送的节流频率以 MPRIS 不抖动为准，实现在代码中调优。

4. INTERFACES

4.1 IPC API

渲染进程经 preload 暴露的单一命名空间 window.lychee 调用以下方法；签名即契约， 行为细节见对应时序图（§3）。 

// 登录（默认：openWebLogin 嵌入官方 xlogin 扫码组件；备选：loginWithCookie 手动 Cookie；createQrKey 为实验性应用内二维码）
login.createQrKey(): Promise<IpcResult<QrSession>>;
login.getStatus(): Promise<IpcResult<AuthStatus>>;
login.loginWithCookie(cookie: string): Promise<IpcResult<AuthStatus>>;
login.openWebLogin(): Promise<IpcResult<AuthStatus>>;
login.refreshSession(): Promise<IpcResult<AuthStatus>>;
login.logout(): Promise<IpcResult<null>>;

// 搜索
search.byType(req: SearchRequest): Promise<IpcResult<SearchResult>>;

// 歌曲
song.getUrls(mids: string[], quality: Quality): Promise<IpcResult<UrlResult[]>>;

// 歌单
playlist.get(id: string): Promise<IpcResult<PlaylistDetail>>;
playlist.listMine(): Promise<IpcResult<PlaylistMeta[]>>;

// 歌词
lyric.get(songMid: string): Promise<IpcResult<Lyric>>;

// 用户资料（仅界面展示；失败不影响登录）
user.getProfile(): Promise<IpcResult<UserProfile>>;

// 设置
settings.get(): Promise<IpcResult<Settings>>;
settings.set(patch: Partial<Settings>): Promise<IpcResult<Settings>>;

// 推送订阅与上报（对应下表通道；订阅方法返回取消订阅函数）
login.onStatus(callback: (status: QrStatus) => void): () => void;
player.sendState(state: PlayerState): void;
player.onCommand(callback: (command: MprisCommand) => void): () => void;

推送事件

方向通道载荷说明
main → rendererlogin:statusQrStatus扫码登录状态推进，见 §3.2
main → rendererplayer:commandMprisCommandMPRIS 反向播放控制命令
renderer → mainplayer:statePlayerState播放器状态发布，主进程转投 MPRIS
  • song.getUrls 要求 mids 为非空数组且长度 ≤ 100，音质只能是三档枚举；越界直接报错。
  • search.byType 的 pageNo 限 1–100，pageSize 限 1–50（缺省 20）。
  • player.sendState 为单向推送，主进程不返回值；渲染进程节流发送。
  • settings.set 以浅合并方式更新并立即写盘。

4.2 消息与错误

type IpcResult<T> = { ok: true; data: T } | { ok: false; error: IpcError };

interface IpcError {
  code: ErrorCode;
  message: string;
}

type ErrorCode =
  | 'UPSTREAM_NETWORK'
  | 'AUTH_EXPIRED'
  | 'NO_STREAM'
  | 'UPSTREAM_CHANGED'
  | 'QUOTA_LIMITED'
  | 'INTERNAL';

type QrStatus = {
  stage: 'waiting' | 'scanned' | 'ok' | 'expired' | 'failed';
  message?: string;
};

interface QrSession {
  imageDataUrl: string;
  expiresAtMs: number;
}

interface AuthStatus {
  loggedIn: boolean;
  musicid: string | null;
  expiresAtMs: number | null;
  canRefresh: boolean;
}

type MprisCommand = 'play' | 'pause' | 'toggle' | 'next' | 'previous' | { seekTo: number };

interface PlayerState {
  song: Song | null;
  status: 'stopped' | 'playing' | 'paused';
  positionMs: number;
  quality: Quality;
}
ErrorCode含义建议动作
UPSTREAM_NETWORK无法连接上游或请求超时提示网络问题，允许用户重试
AUTH_EXPIRED凭证过期或无效清除本地凭证，引导重新扫码登录
NO_STREAM各档音质均无播放链接（VIP / 数字专辑 / 已下架）提示内容不可播并展示原因
UPSTREAM_CHANGED上游响应结构与预期不符记录原始响应待修复，提示稍后再试
QUOTA_LIMITED上游限流指数退避后自动重试
INTERNAL主进程内部错误记录日志，提示重启应用

4.3 数据模型与转换

type Quality = '128k' | '320k' | 'flac';

interface Singer {
  mid: string;
  name: string;
}

interface Album {
  mid: string;
  name: string;
}

interface PayInfo {
  free: boolean;
  vip: boolean;
  album: boolean;
}

interface Song {
  songMid: string;
  songId: string;
  name: string;
  singers: Singer[];
  album: Album;
  durationMs: number;
  pay: PayInfo;
}

interface PlaylistMeta {
  id: string;
  name: string;
  coverUrl: string;
  songCount: number;
}

interface PlaylistDetail {
  meta: PlaylistMeta;
  songs: Song[];
}

interface SearchRequest {
  type: 'song' | 'singer' | 'album' | 'playlist';
  keyword: string;
  pageNo: number;
  pageSize: number;
}

interface SearchResult {
  songs: Song[];
  singers: Singer[];
  albums: Album[];
  playlists: PlaylistMeta[];
  total: number;
}

interface Lyric {
  lrc: string;
  trans: string | null;
}

interface UserProfile {
  nickname: string;
  avatarUrl: string;
}

interface Credential {
  musicid: string;
  musickey: string;
  expiredAtMs: number | null;
  refreshKey?: string;
  refreshToken?: string;
  accessToken?: string;
  openid?: string;
  unionid?: string;
  loginType?: number;
}

interface UrlResult {
  songMid: string;
  url: string | null;
  quality: Quality;
}

interface Settings {
  defaultQuality: 'auto' | Quality;
  closeToTray: boolean;
  theme: 'dark' | 'light';
}

字段定义（Song）

字段含义备注
songMid歌曲业务主键见 TERMS；所有接口按它定位歌曲
songId上游数字 ID 的字符串形式仅个别上游接口需要
durationMs时长（毫秒）上游为秒，转换见下表
pay权限标记驱动 UI 角标与降级提示；不用于绕过授权

数据转换

转换规则
音质 → 流文件128k → 前缀 M500 / .mp3；320k → M800 / .mp3；flac → F000 / .flac（仅用于 vkey 请求的 filename）
播放链接拼装https://ws.stream.qqmusic.qq.com/{purl}；purl 为 vkey 接口返回的相对 URL，其查询参数（guid / vkey / uin / fromtag 等）必须原样保留
上游歌曲 → Songsongmid → songMid 透传；songid 数字转字符串；interval（秒）× 1000 → durationMs；singer[] / album 取 mid 与 name；pay 映射为 PayInfo
上游 pay → PayInfopay_play === 1 且非数字专辑 → vip；price_album > 0 → album；pay_play === 0 且非数字专辑 → free
  • mediaMid 与 guid 仅在 api/song.ts 内部存在，不出现在 IPC 数据模型中。
  • Credential 的 refreshKey / refreshToken / accessToken / openid 等字段仅主进程使用，不跨 IPC。
  • vkey 与 purl 的完整查询串绑定；按固定模板重建查询参数会触发 403，因此只拼接域名与 purl。
  • UrlResult.url 为 null 表示批量请求中该单曲无此档链接；整体请求失败以 IpcError 表达。

4.4 外部接口：MPRIS

对象成员说明
RootIdentity / CanQuit / CanRaise应用名固定 Lychee Player；退出走正常生命周期
PlayerPlaybackStatus / Metadata / Position由 player:state 发布驱动
PlayerPlay / Pause / PlayPause / Next / Previous / Seek / SetPosition转为 MprisCommand 推送回渲染进程
  • D-Bus 总线名为 org.mpris.MediaPlayer2.lychee，playerctl -p lychee 可直接验证。
  • D-Bus / MPRIS 不可用时静默降级，不影响应用内播放。

  • dark 的 purple 在深底上仅适合填充，文字强调用 purple-light；light 的 purple-light 是粉彩填充，压深色文字。
  • dark 的 red 只适合警告级大字 / 图标；正文级错误提示用「红填充 + cream 字」。
  • 深/浅两套 token 色相保持同族（purple 297°、purple-light ~300°、red 347°、gold ~37–39°），切换时视觉语言一致。
