1. TERMS

↑

术语定义
歌曲（Song） 可被搜索、加入播放队列并播放的曲目。展示字段与内部模型见 CORE §4.1 的 Song。
歌手（Singer） 歌曲的表演者，一首歌可有多位，界面以“ / ”连接展示。歌手名可能没有对应的歌手页（mid 为空）：有名字无 mid 时只显示纯文本、不生成链接；名字为空时界面不渲染任何歌手文本，也不显示“未知歌手”占位。
专辑（Album） 歌曲所属专辑；用于列表展示、播放条信息与封面地址推导。
歌手页 / 专辑页 按歌手 / 专辑 mid 打开的信息页：展示名称、封面、简介与歌曲列表，可从歌曲表、播放条与搜索结果进入。歌手名或专辑名缺少 mid 时不生成对应页面链接。
歌单（Playlist） 一组歌曲的集合。分为当前账号的“我的歌单”与公开歌单详情。
播放队列（Queue） 排在当前播放歌曲之后、按播放顺序等待播放的歌曲序列；当前歌曲不属于队列。播放开始时允许用一次临时快照顶替（优先整份缓存，缓存没有当前曲时用已载入页）；歌单完整加载且元数据探测完成后，用最终快照替换。“下一首播放”是手动加入队列的唯一入口。
队列快照（Queue snapshot） 从歌单当前快照生成的播放顺序；在进入队列前剔除已知不可播歌曲，当前曲除外。队列本身不再检测或清理歌曲。临时快照最多使用一次，最终快照要求歌单完整、非 stale 且探测完成。
单曲播放（Single play） 在歌曲列表中点击非当前曲目行携带的播放按钮；以该曲目为当前歌曲并替换播放队列，效果与双击该行相同。当前曲目的按钮用于暂停 / 继续。
下一首播放（Play next） 把对应歌曲插入播放队列头；当前歌曲与队列其余顺序不变。歌曲已在队列中时移动到队列头；歌曲是当前歌曲时不操作；无当前歌曲时直接开始播放该歌曲。队列只支持头部插入，不提供队尾插入；这是手动加入队列的唯一入口。
播放模式（PlayMode） sequence 顺序播放 · repeat-all 列表循环 · repeat-one 单曲循环 · shuffle 随机播放。菜单中四项按此固定相对顺序排列，当前模式固定在菜单底部并高亮。
音质（Quality） 128k 标准 · 320k 高品质 · flac 无损。设置项 auto 不是音质档位，而是按登录态取默认档。
请求音质 / 实际音质 请求音质是用户或设置选择的档位；实际音质是上游最终返回链接对应的档位，可能更低，也可能因仅高音质源而更高。播放条同时展示两者。
登录态（AuthStatus） 渲染进程可见的登录状态；字段定义见 CORE §4.1 的 AuthStatus。渲染进程只持有登录态，不持有凭证。
登录凭证（Credential） 用户登录后由上游签发的访问凭据；数据模型与字段见 PROVIDER §1 与 §4.3。保存与使用边界见 §2。
权限（PayInfo） 歌曲对当前账号的可播属性：免费、VIP 或数字专辑；字段见 CORE §4.1 的 PayInfo。仅用于界面角标，实际可播性以播放链接结果为准。
歌词（Lyric） LRC 原文与可选的翻译文本；支持逐字歌词时按逐字时间轴高亮，界面按时间戳合并翻译。
我喜欢（收藏歌单） 当前账号固定的收藏歌单，不依赖列表位置；详情页统一显示名称“我喜欢”。
从歌单删除 把歌曲从当前普通歌单的成员中移除；不删除本机文件、不改变播放队列与当前播放。仅当前账号可编辑的普通歌单显示该入口，“我喜欢”的移除仍走收藏按钮。
不可播标记 / 最高可用音质 歌单中每首歌的可用性标记：不可播，或当前账号可用的最高音质档位；未知状态按可播处理。
渐进加载（Progressive loading） 歌单先显示第一页，后续歌曲自动补齐；加载期间队列可以为空，当前歌曲单独显示。
最近歌单 按账号保存的最近访问歌单列表，最多 5 条，作为“我的歌单”下的快捷入口；当前正在播放的歌单在列表中高亮。
播放缓存 已播放音频在本机保存的副本，用于再次播放时减少下载；按账号隔离，可清空。缓存可有多个音质档位，缓存达到该曲最高可用档时可直接转为下载（本地转移）；删除下载不删除缓存。
已缓存 / 已下载 两种本机资产：缓存是播放过程中自动写入、供播放复用的音频副本；下载是用户显式保留、记录在下载索引中的离线文件。二者可同时存在；界面同时存在时显示“已下载”，tooltip 补充缓存档位。
缓存进度 当前歌曲音频体写入本机缓存的完成比例，不等于下载任务进度；缓存完成后显示满格 / 对勾。
每日推荐 / 专属雷达 / 猜你喜欢 “发现”页的三个推荐分区：每日推荐取当天动态歌单的 30 首；专属雷达按页取个性化推荐；猜你喜欢为连续推荐流。三者各自刷新、各自缓存 24 小时；未登录显示登录引导。
逐字歌词 按字 / 词时间轴高亮的歌词；没有逐字数据时回退为整行高亮。
收藏 / 歌单管理 / 可编辑歌单 收藏歌曲与“我喜欢”可写；当前账号创建的普通歌单可创建、改名、删除与增删歌曲；公开歌单与他人歌单只读。可编辑歌单指当前账号自建、非“我喜欢”的普通歌单。
MV / MV 清晰度 MV 可搜索、查看详情并取流播放；清晰度分 sd / hd / fhd，默认最高档，档位不可用时自动降档。MV 播放与音频播放状态相互独立。
下载任务 / 下载中心 下载当前账号可播歌曲到本机的任务，以及管理进度、暂停 / 继续、删除的侧栏抽屉。一次整单下载对应一个批次，批次可暂停 / 继续 / 删除 / 重试失败；单任务与批次共用同一状态机。
评论（Comment） 当前歌曲在上游的评论列表；字段见 CORE §4.1 的 Comment。界面展示评论总数、昵称、正文与点赞数。
MPRIS 桌面环境的媒体控制规范；本应用通过 D-Bus 暴露的协议见 PROVIDER §4.4。

2. CONVENTIONS

↑

约定内容
默认音质 Settings.defaultQuality 为 auto 时：已登录取 flac，未登录取 320k；设置页可固定 128k / 320k / flac。
音质回退 请求档位无权限或无链接时静默回退，不弹提示，实际音质显示在播放条；实际音质可能高于或低于请求档位；全部档位无链接时提示不可播。回退规则见 PROVIDER §2。
歌手名缺失 有名字且有 mid：显示歌手名并可进入歌手页；有名字但 mid 为空：只显示纯文本，不生成链接；名字为空：不渲染任何歌手文本，不显示“未知歌手”占位。多条歌手按“ / ”拼接，空名称成员跳过。列表、播放条与详情页共用同一规则。
Revealer 统一交互与样式 除特别说明外，所有 revealer 遵循同一交互与呈现：
交互：按钮本身点击按固定顺序循环切换选项；悬停或键盘聚焦展开弹层，离开 / 失焦关闭；Esc 或点击外部关闭；同一时间只展开一个弹层。弹层按固定顺序列出除当前项外的其它选项，按钮本身始终表示并高亮当前项。
呈现：弹层从按钮底部向上展开，宽度与按钮一致并左右对齐；按钮位于弹层底部、始终可见且层级高于弹层；当前项不在弹层内重复出现。弹层使用面板底色与向上阴影；所有 revealer 按钮不带边框；弹层选项悬停背景统一使用 --subtle-bg。
特殊个例在对应组件章节单独说明，不在本约定中列举。
播放模式切换 按 Revealer 统一交互执行，固定顺序为 sequence → repeat-all → repeat-one → shuffle；点击按钮按该顺序循环，悬停 / 键盘聚焦展开其余选项。切换立即生效且不弹 Toast。
歌单加载与后台刷新 再次进入已打开歌单时先显示整份缓存；第一页成功即显示；加载中断可重试并自动续传；歌单页可见时每 15 秒轮询一次（页面不可见时跳过）。刷新失败保留已显示内容并提示；退出登录清空本机歌单数据。不再预取“我喜欢”第一页。
收藏后刷新 收藏 / 取消收藏成功后立即递增收藏版本，刷新“我喜欢”歌单与“我的歌单”卡片；失败回滚且不刷新。
启动参数文件 默认路径为 $XDG_CONFIG_HOME/lychee-player/flags.conf（未设置时 ~/.config/lychee-player/flags.conf）；每行一个参数，空行与 # 开头行忽略；文件上限 8 KiB / 64 行，非法 switch 被过滤。优先级为显式命令行 > 文件 > 环境变量 > 内置默认；保存后下次启动生效。
不可播标记与最高可用音质 歌单加载后逐步显示每首歌的不可播标记与最高可用音质；标记出现不阻塞列表；未知状态按可播处理。
渐进加载 第一页成功即显示；后续页自动补齐；最终队列快照要求完整加载、非 stale 且元数据探测完成。完成前允许一次临时快照顶替；已知不可播歌曲在进入快照前剔除。
最近歌单 按账号保存的最近访问歌单列表，最多 5 条，作为“我的歌单”下的快捷入口；当前正在播放的歌单在列表中高亮。
最近歌单 最多 5 条，按账号持久化；进入歌单页时更新并置顶，超出淘汰最旧。登录后与每次展开窄屏侧栏时校验（宽屏首次渲染也校验一次），校验带 5 秒节流与单飞。已删除或无权限的歌单从列表移除且不补位；校验失败保留条目并标记失效。当前正在播放的歌单高亮，与当前路由无关。
播放缓存 按账号隔离；有容量上限、可手动清空；退出登录不清空；缓存内容仅本机播放；不做下一首预解析。
播放失败 不可播（无可用流）时播放条沿队列向后尝试到可播或队列空；连续 10 首不可播即停止自动切歌并提示，避免鉴权异常时无限切歌。链接过期 / 流中断时同一歌曲最多每 30 秒自动重取一次链接并从原位置继续，再次失败才提示。其他加载失败仍停止当前加载并提示错误，不自动跳下一首、不自动回退上一首。顺序播放到队尾时停止。
乐观更新与回滚 收藏、歌单创建 / 改名 / 删除、添加歌曲与从歌单删除等写操作先更新界面或写后刷新；失败时回滚并提示。从歌单删除失败时恢复被删行与歌曲数；添加到歌单重复时不重复提交并提示。
缓存与下载 点击下载先检查缓存：缓存档位达到该曲最高可用档时走本地转移登记为下载（优先硬链接，失败回退复制），否则按最高可用档新建下载；已有同曲任务时聚焦任务而不重复创建。
下载限制 仅下载当前账号可播内容；批次按歌单顺序建任务，每首按 flac → 320k → 128k 选择最高可用档；下载并发固定为 1；已下载同档跳过，缓存达到最高档时本地转移；失败不自动无限重试；下载文件仅供本机个人使用。
登录凭证边界 凭证只存在于主进程；渲染进程只消费登录态。扫码与 Cookie 登录会保存登录网页会话 Cookie（webCookies）用于收藏写入，仍只存在于主进程并加密保存；凭证不会跨 IPC。系统密钥环不可用时禁用登录，绝不退化为明文保存。
主题 通过 <html data-theme="dark|light"> 切换，选择持久化在 Settings.theme；组件只使用语义变量，不直接写死颜色。
关闭行为 Settings.closeToTray 默认开启：关闭主窗口时隐藏到托盘；主界面侧栏“退出”或设置页“退出应用”可直接结束进程，不受该设置影响，托盘菜单同样保留“退出”。
页面 / URL 跳转 页面与跳转关系见 §3.4；Hash 路由。歌词 / 评论为普通路由页 /lyrics：返回优先 router.back()，无历史时回 /search；页面由路由直接渲染。

3. DIAGRAMS

↑

3.1 总体架构

  • 音频流由应用主进程统一代理：缓存命中走 lychee-audio://file/...，未命中走 lychee-audio://stream/<token> 由主进程转发 Range 并写缓存；渲染进程不直接访问上游流，也不持有上游链接。
  • seek 不再等待整段 stream：浏览器每次 Range 都会独立转发；未缓存歌曲可立即从目标位置分段取流。缓存命中时由主进程按 Range 切片返回 206；连续 seek 同样逐次转发。完整响应才落盘，局部 206 不缓存。
  • 凭证与密钥环边界见 §2。
  • MPRIS 协议见 PROVIDER §4.4；命令接收后的内部调用路径见 CORE §5.6。

3.2 登录

  • 登录方式二选一：扫码（默认，内嵌官方 xlogin）或 Cookie（兜底）。
  • 扫码分支的详细协议见 PROVIDER §3.1；Cookie 分支见 PROVIDER §3.2。USER 只描述方式选择与结果，不重复协议细节。
  • 登录成功后自动进入“我的歌单”；扫码失败时提供“重新加载登录组件”，Cookie 无效时提示重新获取。
  • 凭证在主进程内直接入库；保存与使用边界见 §2。

3.3 播放单曲

  • 双击歌曲、“播放全部”与单曲播放都会替换播放队列；“下一首播放”只把歌曲插入队列头，不改变当前歌曲。
  • 播放队列入口与面板见 §5.2.9；不可播处理见该节，其他加载失败不自动跳过，文案见 §5.3。
  • 实际音质可能与请求音质不同；播放条以标记展示实际档位。
  • 上游链接获取协议见 PROVIDER §3.3。

3.4 页面 / URL 架构图

  • 节点为页面，边为跳转关系；根路径 / 重定向到 /search。
  • 歌单详情的返回入口指向 /library；登录成功后进入 /library。
  • “发现”为 /discover，MV 播放页为 /mv/:id；歌词 / 评论为 /lyrics，入口是任意页面播放条的封面；歌手页 / 专辑页为 /artist/:mid / /album/:mid；下载中心为侧栏抽屉，不占独立路由。
  • 页面结构与视觉契约见 §5.2.8。

歌单详情 歌单头图（封面 180px、名称、歌曲数 / 歌单 ID / 已载入数、播放全部、下载全部）+ 歌曲表；再次进入先显示整份缓存快照，第一页渲染后底部显示加载 / 重试与已载入 / 总数；加载中断可重试并自动续传，不完整缓存显示为中断状态。页面可见时每 15 秒轮询歌单变化；底部 spinner 正常显示。队列可先用缓存临时顶替，最终快照就绪后替换。“下载全部”按歌单顺序把可播歌曲加入一个批次，按钮显示完成 / 总数 / 失败；全部完成显示“已全部下载”，部分失败提示到下载中心重试。
歌手页 / 专辑页 路由 /artist/:mid / /album/:mid；展示名称、封面、简介（上游返回时）、歌曲数与歌曲表。分页加载，支持播放、下一首播放、收藏、下载与加入歌单；歌手页的歌曲可直接进入专辑页，专辑页的歌手可进入歌手页；加载中、空状态与失败重试；返回优先历史。
歌词 / 评论页 /lyrics 路由页：顶部返回与歌名 / 歌手 / 专辑，无独立标题行；左右各 50%，中间分隔线；左歌词当前行居中高亮、上下渐隐、支持拖拽 / 滚轮 / 点击定位；右评论默认最新排序，右上仅刷新评论，滚动分页与点赞；无当前歌曲时为空状态。
发现 “每日推荐 / 专属雷达 / 猜你喜欢”三个分区，各自提供刷新入口；每区固定高度显示 3 行、上下滚动，条目固定宽度（封面图标 + 上方歌名、下方歌手，超长走马灯）。未登录显示登录引导；分区空结果显示空状态，失败显示该区错误与重试。
MV 播放 视频播放器 + 标题 / 歌手 / 清晰度选择；搜索结果中的 MV 卡片进入本页。默认最高清晰度并自动播放，档位不可用时按 fhd → hd → sd 降档；使用原生视频控制，支持全屏与退出全屏恢复（保持播放位置与状态，不做离开页面后的续播）。
下载中心 右侧抽屉；按批次分组，显示批次汇总、任务来源（缓存转移 / 网络下载）、缓存转移标记、按账号索引；提供批次级暂停 / 继续 / 删除 / 重试失败与单任务操作；“清除已完成”只清记录，删除批次 / 单任务才删文件；不新增路由。
Toast 固定于右下、播放条上方；3.6 秒自动消失；info 左侧 accent 边，error 左侧 danger 边。

5.3 错误与通知

ErrorCode界面提示行为
UPSTREAM_NETWORK网络异常，请稍后重试；播放链接被上游拒绝时提示检查网络 / VPN / 代理出口保留当前状态，允许用户重试。
AUTH_EXPIRED登录已失效，请重新登录提示用户前往登录页；不自动清除凭证。
NO_STREAM按账号权限与内容状态提示：需要 VIP / 购买、播放授权异常，或可能需要 VIP / 已下架播放条沿队列向后尝试到可播；连续 10 首不可播或队列为空时停止。
UPSTREAM_CHANGED上游接口发生变化；收藏相关可显示上游 80105 / 1101 文案提示稍后再试；保留当前状态。80105 提示退出后重新登录（扫码或 Cookie）以同步网页会话；1101 提示该歌曲暂不支持收藏。
QUOTA_LIMITED请求过于频繁，请稍后重试提示稍后再试；用户可手动重试。
NO_PERMISSION当前账号无权执行该操作；播放设备受限时提示当前设备无法播放保留原状态；不可编辑的歌单不显示编辑入口。
INTERNAL主进程内部错误提示主进程内部错误，详情只写入主进程日志。
  • 展示方式：页面级数据加载失败使用页面内联错误区并提供重试；用户操作失败使用 Toast。错误码文案与行为见上表。
  • 错误码的完整定义见 CORE §4.1；上游错误码到内部错误码的映射见 PROVIDER §4.2。
  • NO_STREAM 的文案按权限、付费状态与播放结果选择，无法判断时回退到 VIP 状态与通用提示；连续 10 首不可播时停止自动切歌并提示检查登录或稍后重试。上游播放结果到内部错误码的具体映射见 PROVIDER §4.2。“不可播”只影响当前曲与自动切歌，不改变已有队列。
  • 音频加载失败时先自动重取一次链接（同一歌曲 30 秒内只重试一次）并保留播放位置；再次失败才显示“音频加载失败，可能链接已过期”。
  • 收藏成功只以写后读回与成员可见性为准；业务码成功、状态接口为 true 或总数增加都不单独显示成功，避免出现官方歌单 / 手机端看不到的“假成功”。
  • 歌单可用性标记获取失败时静默保留未知状态，不弹错误；播放失败仍按本表提示。
  • “从歌单删除”失败时按 NO_PERMISSION / 网络错误提示并恢复被删行与歌曲数；删除只改变歌单成员，不改变当前播放与队列。
  • 下载：本地转移失败自动回退为正常下载，不新增错误码；删除批次需确认，删除单任务 / 批次才删文件，“清除已完成”只清记录。缓存清理与下载删除互不影响。
  • 登录流程中的具体失败原因（验证码、设备限制等）由上游返回；界面是否展示原始原因取决于错误映射策略。
  • 歌词 / 评论页的数据加载失败使用页内错误区与重试；排序切换或滚动分页失败保留已加载内容并提示；右上刷新只影响评论。点赞失败回滚并 Toast；这些都不新增错误码，复用现有映射。
  • 推荐分区失败只影响该区，保留其余分区并提示重试；MV 详情 / 取流失败显示页内错误与重试；歌单创建 / 改名 / 删除 / 添加歌曲失败保留原状态并提示，AUTH_EXPIRED 引导重新登录，NO_PERMISSION 提示不可编辑。

5.4 托盘

菜单项行为
显示主窗口恢复并聚焦主窗口；单击托盘图标同样触发。
播放 / 暂停按最新播放状态解析为明确的播放或暂停命令，单击一次即生效。
上一首 / 下一首向渲染进程发送 previous / next 命令。
退出 Lychee Player结束应用进程，不受“关闭到托盘”影响。
  • 托盘菜单、启用状态与 tooltip 随播放状态更新；无当前歌曲时播放控制项禁用。托盘图标不随播放 / 暂停切换（当前没有两套图标资源）。
  • 单击托盘图标只显示主窗口，不切换隐藏；关闭窗口行为沿用“关闭到托盘”设置。
  • 托盘“播放 / 暂停”保证单次点击生效：命令基于最新播放状态解析为明确的播放或暂停；短时间重复点击只保留最新一条。窗口隐藏、菜单重建后首次点击同样生效。
  • GNOME 需要 AppIndicator 扩展，托盘图标可能被桌面隐藏；部分桌面的 AppIndicator 会延迟首次点击响应，这是外部限制，应用侧已做状态解析与去重兜底。扩展不随应用打包；托盘初始化失败时静默降级。
