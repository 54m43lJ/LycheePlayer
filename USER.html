1. TERMS

↑

术语定义
歌曲（Song） 可被搜索、加入播放队列并播放的曲目。展示字段与内部模型见 CORE §4.1 的 Song。
歌手（Singer） 歌曲的表演者，一首歌可有多位。界面以“ / ”连接展示。
专辑（Album） 歌曲所属专辑；用于列表展示、播放条信息与封面地址推导。
歌单（Playlist） 一组歌曲的集合。分为当前账号的“我的歌单”与公开歌单详情。
播放队列（Queue） 当前播放上下文中的歌曲序列。双击歌曲或“播放全部”会替换队列；单曲播放会追加到队尾。
播放模式（PlayMode） sequence 顺序播放 · repeat-all 列表循环 · repeat-one 单曲循环 · shuffle 随机播放。
音质（Quality） 128k 标准 · 320k 高品质 · flac 无损。设置项 auto 不是音质档位，而是按登录态取默认档。
请求音质 / 实际音质 请求音质是用户或设置选择的档位；实际音质是上游最终返回链接对应的档位，可能更低。播放条同时展示两者。
登录态（AuthStatus） 渲染进程可见的登录状态；字段定义见 CORE §4.1 的 AuthStatus。渲染进程只持有登录态，不持有凭证。
登录凭证（Credential） 用户登录后由上游签发的访问凭据；数据模型与字段见 PROVIDER §1 与 §4.3。仅保存在主进程，不跨 IPC、不写入日志、不进入渲染进程。
权限（PayInfo） 歌曲对当前账号的可播属性：免费、VIP 或数字专辑；字段见 CORE §4.1 的 PayInfo。仅用于界面角标，实际可播性以播放链接结果为准。
歌词（Lyric） LRC 原文与可选的翻译文本；界面按时间戳合并展示。
MPRIS freedesktop 媒体播放器 D-Bus 接口规范（org.mpris.MediaPlayer2），本应用对桌面环境暴露的媒体控制接口。

2. CONVENTIONS

↑

约定内容
默认音质 Settings.defaultQuality 为 auto 时：已登录取 flac，未登录取 320k；设置页可固定 128k / 320k / flac。
音质降档 请求档位无权限或无链接时，按 flac → 320k → 128k 静默降档；不弹提示，实际音质显示在播放条。全部档位无链接时提示不可播。协议细节见 PROVIDER §2。
播放模式切换 按 sequence → repeat-all → repeat-one → shuffle 循环切换，并通过 Toast 显示当前模式。
播放失败 单曲加载失败时停止当前加载并提示错误，不自动跳到下一首；顺序播放到队尾时停止。
登录凭证边界 凭证只存在于主进程；渲染进程只消费登录态。系统密钥环不可用时禁用登录，绝不退化为明文保存。
主题 通过 <html data-theme="dark|light"> 切换，选择持久化在 Settings.theme；组件只使用语义变量，不直接写死颜色。
关闭行为 Settings.closeToTray 默认开启：关闭主窗口时隐藏到托盘；仅在托盘菜单选择“退出”时结束进程。
路由 Hash 路由；页面为 /search、/library、/playlist/:id、/login、/settings，根路径重定向到 /search。切换路由自动关闭歌词面板。
错误展示 所有请求型 IPC 错误以 Toast 展示；错误码到界面文案的映射见 §5.3。

3. DIAGRAMS

↑

3.1 总体架构

  • 音频流由渲染进程直接从流服务器加载，不经过主进程转发。
  • 凭证仅存在于主进程；渲染进程只持有登录态。
  • MPRIS 协议见 PROVIDER §4.4；命令接收后的内部调用路径见 CORE §5.6。
  • 系统密钥环不可用时，登录功能禁用；免费内容的搜索与播放不受影响。

3.2 登录

  • 登录方式二选一：扫码（默认，内嵌官方 xlogin）或 Cookie（兜底）。
  • 扫码分支的详细协议见 PROVIDER §3.1；Cookie 分支见 PROVIDER §3.2。USER 只描述方式选择与结果，不重复协议细节。
  • 登录成功后自动进入“我的歌单”；扫码失败时提供“重新加载登录组件”，Cookie 无效时提示重新获取。
  • 凭证在主进程内直接入库，任何状态下都不跨 IPC 下发。

3.3 播放单曲

  • 双击歌曲或“播放全部”会替换播放队列；单曲播放会追加到队尾。
  • 无可播链接时提示不可播，不自动跳过；具体文案见 §5.3。
  • 实际音质可能低于请求音质；播放条以标记展示实际档位。
  • 上游链接获取协议见 PROVIDER §3.3。

5.3 错误与通知

ErrorCode界面提示行为
UPSTREAM_NETWORK网络异常，请稍后重试保留当前状态，允许用户重试。
AUTH_EXPIRED登录已失效，请重新登录提示用户前往登录页；不自动清除凭证。
NO_STREAM当前内容不可播放（可能需要 VIP 或已下架）停止当前加载，不自动跳下一首。
UPSTREAM_CHANGED上游接口发生变化提示稍后再试；保留当前状态。
QUOTA_LIMITED请求过于频繁，请稍后重试提示稍后再试；用户可手动重试。
INTERNAL主进程内部错误提示重启应用；详情只写入主进程日志。
  • 错误码的完整定义见 CORE §4.1；上游错误码到内部错误码的映射见 PROVIDER §4.2。
  • 登录流程中的具体失败原因（验证码、设备限制等）由上游返回；界面是否展示原始原因取决于错误映射策略。

5.4 托盘

菜单项行为
显示主窗口恢复并聚焦主窗口；单击托盘图标同样触发。
播放 / 暂停向渲染进程发送 toggle 命令。
上一首 / 下一首向渲染进程发送 previous / next 命令。
